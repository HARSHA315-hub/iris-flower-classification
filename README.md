
# Iris Flower Classification

A machine learning web application that predicts Iris flower species using four flower measurements.

## Features

- Predict Iris species using sepal and petal measurements
- Compare machine learning classification models
- Display prediction probabilities
- Store prediction history in a database
- View prediction statistics on a dashboard
- Export prediction history as CSV

## Technologies Used

- Python
- Flask
- Scikit-learn
- Pandas and NumPy
- Flask-SQLAlchemy
- SQLite
- HTML, CSS and JavaScript
- Chart.js

## Installation

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install dependencies:

   pip install -r requirements.txt

4. Run the application:

   python app.py

5. Open http://127.0.0.1:5000 in your browser.

## Project Structure

- `app.py` — Flask routes and application
- `models.py` — Database model
- `preprocessing.py` — Dataset preprocessing
- `train_models.py` — Model training and evaluation
- `models/` — Saved trained model
- `templates/` — HTML pages
- `static/` — CSS and frontend assets
